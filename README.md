# Public Facility Accessibility Assessment

## Project Description
This project evaluates accessibility features in public facilities, including ramps, lifts, accessible toilets, and designated parking. It helps identify accessibility barriers and calculate availability and usability percentages to support inclusive infrastructure.

## Technologies Used
- **Programming Language:** Python
- **Framework:** Flask
- **Database:** SQLite
- **Frontend:** HTML and CSS

## Features
- Enter public facility details.
- Assess accessibility feature availability and usability.
- Record observations and accessibility problems.
- Calculate accessibility percentages.
- Save and retrieve assessment records using SQLite.

## How to Run
1. Install Python.
2. Install Flask using `python -m pip install flask`.
3. Run `python app.py`.
4. Open `http://127.0.0.1:5000` in your browser.

The SQLite database is created automatically when the application starts.

## Objective
To assess accessibility in public facilities and encourage safer, more inclusive environments for everyone.
